Import

Bring entries in from a CSV — the same column layout the Journal's own Export CSV produces, so export → edit in a spreadsheet → re-import is a real round trip. Required columns: Entry # (groups rows into one entry — the value itself isn't kept), Date, Description, Account code, and exactly one of Debit / Credit per row. Reference, Payee, and Memo are optional; Scenario and Account name are ignored if present. Every entry in a group must balance on its own.

Nothing posts straight to a scenario — imported entries land in Staging for review, same as a scheduled entry. Pick where they should end up once approved below, then review and approve them when you're ready.
