Connecting from outside this machine

By default Postgres only accepts connections from this machine itself — that's what keeps {{ bi_user }}'s fixed password safe even though it's the same for every install. Reaching it from another machine (a GCP-deployed instance, say) needs a tunnel first — see "Connecting Power BI / Excel" in deploy/gcp/README.md. If you do widen Postgres's own port beyond localhost, change this password first — ALTER ROLE {{ bi_user }} WITH PASSWORD 'something-only-you-know'; in psql — the same way the README already tells you to change the app's own postwarden/postwarden login before doing that.
